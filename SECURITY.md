# Security policy

## Supported versions

Security fixes go into the latest 1.x release. Older versions don't get backports.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub's private vulnerability reporting: on the repo's Security tab, choose "Report a vulnerability". Include what you found, how to reproduce it, and the module version.

How the module itself is secured (IAM, RBAC, encryption, network, logging) is in [docs/security-design.md](docs/security-design.md).
